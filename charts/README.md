# HouyiDB Helm chart repository

```bash
helm repo add houyidb https://houyidb.top/charts/
helm repo update
helm search repo houyidb
helm install houyidb houyidb/houyidb --namespace houyidb --create-namespace
```

Source chart: <https://github.com/houyidb-community/houyidb/tree/main/deploy/helm/houyidb>

This directory only contains packaged chart artifacts and `index.yaml` generated by
`helm repo index`; edit the source chart, not the packaged files.

中文：本目录只放打包后的 chart 和 `index.yaml`；请修改主仓
`deploy/helm/houyidb` 下的源 chart，再重新打包并生成索引。
